# KIMA 组件库 HOP 全面重构清单

> 状态只表示有证据的完成情况：写了代码不等于完成；只有目标浏览器的真实交互、中间帧、终态、可访问性与构建检查都过，才可打勾。每项应先审查旧实现，保留截图/几何证据，再按单个组件或紧密组件族提交。

## HOP 工作约束

- [ ] **一个来源**：每项设计决策（尺寸、间距、动效时间、颜色角色、方向语义）只定义一次；生成结果明确标成派生物。
- [ ] **按业务主体放置**：组件、主题、布局、动效规则放在接手者会寻找的位置；不为一两个调用者制造新层。
- [ ] **直线流程**：更新状态 → 明确进入/退出/移动 → 清理；避免多层 Transition 和 watcher 相互控制同一视觉状态。
- [ ] **边界检查**：只在用户输入、浏览器环境、公开 API 边界验证；内部组件遵守统一契约。
- [ ] **自然命名与注释**：名字表达用户看到的行为；注释讲“为什么/业务语义”，不复述语法。
- [ ] **修问题做减法**：先找结构原因，能删重复动画、重复尺寸或局部例外，就不继续加补丁。
- [ ] **尊重现有公开 API**：标签、属性、事件、插槽默认不破坏；确需变更时先单独列出影响。
- [ ] **每个小切片都可见、可测、可回退**：提交粒度小；不把海量改动攒成一次全库大爆炸。

## 全库统一验收门槛（每个组件都执行）

- [ ] 先描述基线缺陷与根因，保存修改前截图/尺寸/关键 DOM 状态。
- [ ] 明确组件默认宽度、最小宽度、最大宽度、内容极值和窄屏行为。
- [ ] 检查根容器与内部元素的 Flex/Grid 对齐、伸缩、换行、溢出；块级场地占满可用宽度。
- [ ] 检查默认态、悬停、键盘聚焦、按下、禁用、加载、空态、错误态、内容最长/最短态。
- [ ] 对有动效的交互记录 before、首帧、25%、50%、75%、95%、after；检查快速反向与连续触发。
- [ ] 新旧内容交叉期间，不因旧节点仍占流/脱流造成宽高突变；高度、宽度和子项位移分别验收。

- [ ] `prefers-reduced-motion` / KIMA reduced motion 下无明显位移/循环，状态及可访问性不延迟。
- [ ] 验证键盘、焦点保持/返回、读屏角色、`aria-live`、`inert` 与退场期间可交互性。

- [ ] 修完后重跑目标场景及相邻组件，运行适用的构建/SSR/浏览器测试，再截图复核。
- [ ] 证据过关后按中文 Conventional Commits 单独提交并推送；清单更新与代码同提交。

## 本轮根因研究：集合动效不是“补一段 FLIP”

| 已证实问题 | 证据 | 根因处理 |
| --- | --- | --- |
| 同一节点两个位移执行器 | 点击时同时存在 Vue transform transition 与自定义 WAAPI | 禁用 Vue move；共享入口负责所有集合位移，不在点击处理里 capture/play |
| 目标采样过早 | 更新阶段读到四个零位移，实际 DOM 尚未完成集合更新 | 集合源更新前读当前视觉帧；更新后等待完整 tick，再批量读取自然目标和写动画 |
| 只动画根高度，内部控制区仍先跳 | 新增时内部触发器首帧直接移动约一整行 | MultiSelect 单独设置芯片占位盒，控制区由正常排版跟随 |
| 直线/独立折线仍碰撞 | 280px 对角互穿；扩大到 480px 后在 240ms 再现同排项与跨行项相撞 | 集合共用两段让位节奏，同排项不能提前冲进跨行项尚未腾出的区域；保留反例回归 |
| 高度结束交接空档 | 800ms 附近占位盒短暂回到旧高度，控制区穿过芯片 | 终帧保持到清理；先恢复自然布局，再取消动画 |
| 无关属性更新重启动画 | 全组件更新钩子与集合变化范围不一致 | 位移和高度订阅同一集合源，名称/搜索等无关更新不取消原动画 |
| List 网格行被旧占位拉伸 | 352px 高度下剩余两条 104px 行变成 170px，第三项偏移 66px | 用 align-content:start 表达内容自然靠前排列，不让动画外盒决定行高 |
| List 几何通过但文字仍穿过 | 固定时钟截图中 Alpha 与 Beta/Gamma 同时可见且重叠 | 复用共享先退出再补位；增加可见矩形碰撞检查，不以截图问题为“正常动画” |

### 职责与边界

- `useCollectionMotion()` 是集合接入点：指定高度承载盒、数据源、子项容器；组件不复制时长/延迟/overflow 参数组合。
- 位移只写子项 transform；presence 只写子项 opacity；占位只写高度盒 height。Popover 定位与开关不等待集合动画。
- 业务值、事件、原生表单立即同步；视觉顺序是退出 → 让位/调整占位 → 显现新增项。
- 测试暂停在固定毫秒并保存动画引用；已清理的动画不人为复活。旧测试没有真正暂停、更新后才取 before、放宽容差的做法不能作为证据。
- 当前自动化是 Chromium 已列出的数据与宽度，不是任意多行布局路径安全的数学保证。任意排序、动态字体/resize、多项同时替换、反向全过程、其他浏览器仍待专项。
- 所有权冲突包含早期助手自己引入的实现错误，不是 Vue 框架缺陷。构建/测试数量不替代默认速度体验和逐组件验收。
